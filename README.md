AI engineering student in Almaty. I build small Python tools for real business
problems: finding where CRM leads get lost and automating content for Telegram

## Projects

- **[bitrix24-deal-analyzer](https://github.com/ISkerow/bitrix24-deal-analyzer)** —
  finds where incoming leads get lost in a Bitrix24 CRM: stuck deals by channel,
  manager and working hours, with a one-page HTML report.
  *Python, pandas, pytest, GitHub Actions.*
- **[ev-news-bot](https://github.com/ISkerow/ev-news-bot)** — Telegram bot that
  collects EV news from RSS, filters it by brand, rewrites it with Gemini and
  posts it with enquiry buttons.
  *Python, aiogram, Gemini API, Docker.*
